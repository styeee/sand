# sand

2D-песочница на C++ с Lua-скриптами. Это серверная часть проекта.

## Версии

### 0.1.1

- Добавлен `loop` — цикл с фиксированным шагом.
- Добавлен `timer` — вспомогательный класс для работы со временем.

## Классы

### `world`

Мир с именем.

- `world(name)` — создать мир с именем.
- `name()` — получить имя.
- `rename(name)` — переименовать.

### `universe`

Менеджер миров.

- `create(name)` — создать мир; `false`, если имя занято.
- `remove(name)` — удалить мир; `false`, если не найден.
- `find(name)` — найти мир; `nullptr`, если не найден.
- `rename(old, new)` — переименовать; `false`, если старое имя не найдено или новое занято.
- `change(name)` — сделать мир текущим; `false`, если не найден.
- `current()` — текущий мир; `nullptr`, если не выбран.
- `count()` — количество миров.
- `each(f)` — обойти все миры, вызывая `f(world&)`.

### `timer`

Вспомогательный класс для работы со временем.

- `timer()` — запустить отсчёт.
- `now()` — секунды с момента создания.
- `wait(t)` — подождать `t` секунд.

### `loop`

Цикл с фиксированным шагом.

- `rate()` — текущий шаг в секундах.
- `rate(x)` — задать шаг.
- `handle(f)` — задать обработчик `f(t)`, возвращающий `false` для остановки.
- `run()` — запустить цикл.

## Демки

### `universe`

Консольный менеджер миров. Читает команды из stdin и выводит результат в stdout.

Команды:

- `create <name>` — создать мир; выводит `ok` или `exists`.
- `remove <name>` — удалить мир; выводит `ok` или `not_found`.
- `rename <old> <new>` — переименовать мир; выводит `ok` или `failed`.
- `change <name>` — сделать мир текущим; выводит `ok` или `not_found`.
- `current` — показать текущий мир или `none`.
- `count` — количество миров.
- `list` — список миров, завершается `.`.
- `help` — справка.
- `quit` — выход.

### `loop`

Демка цикла с фиксированным шагом. На каждом тике читает число из stdin и печатает `<тик>:<квадрат числа>`, затем останавливается, когда тик достигает `end`.

Запуск: `./loop [end] [rate]`, где `end` — номер последнего тика (по умолчанию 10), `rate` — шаг в секундах (по умолчанию 0.0001).
